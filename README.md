# Personal Academic Website - PKU Red and White Version

This is a separate PKU red-and-white academic homepage package with a pure white background. The original `personal-site` folder is unchanged.

## How to edit

1. Replace `Your Name`, `中文名`, `your.email@example.com`, and profile links in `index.html`.
2. Put your portrait and publication illustrations in the `image` folder.
3. Put your CV at `assets/cv.pdf`, or remove the CV link.
4. Edit the Welcome, Educations, Honors and Awards, News, Publications, Projects, Research, and Contact sections.
5. Adjust the PKU red and neutral gray theme tokens in `style.css` if needed.

## How to publish with GitHub Pages

1. Create a GitHub repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Copy the files inside this `personal-site-pku` folder to the root of that repository.
3. Commit and push to the `main` branch.
4. In the GitHub repository, open `Settings -> Pages`.
5. Set the source to deploy from the `main` branch root.
6. Visit `https://YOUR_GITHUB_USERNAME.github.io/` after GitHub finishes deployment.

GitHub Pages hosts static HTML, CSS, and JavaScript directly, so no backend server is required for this template.
